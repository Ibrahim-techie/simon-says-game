# Simon Says Game

A browser-based implementation of the classic **Simon Says** memory game built using **HTML, CSS, and JavaScript**.

## Overview

Simon Says is a memory-based game where the player must repeat an increasingly long sequence of button flashes generated by the computer.

At each level:

1. The game adds a new random color to the sequence.
2. The sequence is replayed to the user.
3. The user must click the buttons in the exact same order.
4. If the sequence is correct, the game advances to the next level.
5. If the user makes a mistake, the game ends and can be restarted.

---

* Interactive 2×2 Simon board

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder.

3. Launch `index.html` in your browser.

No additional dependencies or setup are required.

---

## Game Controls

* Press any key to start the game.
* Watch the sequence carefully.
* Repeat the sequence by clicking the colored buttons.
* Continue advancing through levels.
* If you click the wrong button, the game ends.
